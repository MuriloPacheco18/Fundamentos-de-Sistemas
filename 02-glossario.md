# Glossário ou vocabulário da disciplina
Neste arquivo, são armazenadas palavras ou expressões estudadas na disciplina, com uma breve descrição delas

## Palavras ou Expressões
  - <b>CaaS</b>: Credit as a Service (Crédito como Serviço), um modelo onde empresas não financeiras oferecem crédito próprio (empréstimos/financiamentos) via APIs, sem precisar de licença bancária.
  - <b>CRUD</b>: é um acrônimo para as quatro operações básicas de armazenamento persistente em sistemas de banco de dados: Create (Criar), Read (Ler/Consultar), Update (Atualizar) e Delete (Excluir)
  - <b>DaaS</b>: O usuário acessa uma área de trabalho completa (Windows ou Linux) através de um navegador ou um app leve em qualquer dispositivo (um tablet, um PC antigo ou até um celular). Exemplo:Windows 365
  - <b>DBaaS</b>: é o modelo onde você "aluga" apenas a funcionalidade do banco de dados, sem precisar gerenciar o servidor, o sistema operacional ou a instalação do software. Exemplo:Microsoft Azure
  - <b>FaaS</b>: É popularmente conhecido como Serverless (Computação sem Servidor), que ativa quando eventos específicos acontecem, ou seja um servidor que não é 24 horas por dia. Exemplo:Google Cloud
  - <b>IaaS</b>: É um modelo de computação em nuvem que deixa tudo manual e editavel a gosto do comprador. Exemplo:Microsoft Azure
  - <b>Iot</b>:Refere-se a uma rede de objetos físicos — "coisas" — equipados com sensores, software e tecnologias que conectam e trocam dados via internet. Exemplo:Alexa
  - <b>PaaS</b>: É um modelo de computação nuvem que oferece espaço para desenvolvedores,já vem pronto as partes chatas. Exemplo:Google App Engine
  - <b>SaaS</b>: É um software pronto para uso via navegador ou app. Você é apenas o usuário; não vê código, nem servidor, nem banco de dados. Exemplo:Netflix
  - <b>SPT</b>: Sistemas de Processamento de Transações, são responsáveis por registrar e processar operações do dia a dia de uma organização, como vendas, pagamentos e controle de estoque. Exemplo: sistema de vendas de uma rede como Walmart
  - <b>SIG</b>: Sistemas de Informação Gerencial, organizam e transformam dados operacionais em informações úteis para os gestores. Com eles, é possível gerar relatórios e acompanhar o desempenho da empresa. Exemplo: relatórios gerenciais usados por empresas como Ambev
  - <b>SAD</b>: Sistemas de Apoio à Decisão, ajudam na tomada de decisões mais complexas, analisando dados e simulando diferentes cenários. Exemplo: sistemas de análise de dados da Netflix
  - <b>SIE</b>: Sistemas de Informação Executiva, são voltados para os altos executivos, apresentando informações estratégicas de forma clara e rápida, geralmente por meio de gráficos e dashboards. Exemplo: dashboards usados por executivos da Google
  - <b>SE</b>: Sistemas Especialistas, utilizam inteligência artificial para simular o conhecimento de um especialista humano. Eles são capazes de analisar situações específicas e oferecer soluções ou diagnósticos. Exemplo: sistema médico como o IBM Watson Health
  - <b>ERP</b>: Sistemas ERP(Planejamento de Recursos Empresariais), integram todos os setores de uma empresa em um único sistema. Eles permitem o controle centralizado de informações, como finanças, recursos humanos e logística, aumentando a eficiência organizacional.Exemplo: ERP usado por empresas como Nestlé
  - <b>CRM</b>: Sistemas CRM (Gestão de Relacionamento com o Cliente), são utilizados para gerenciar o relacionamento com clientes. Eles ajudam a acompanhar vendas, armazenar informações de contato e melhorar o atendimento, contribuindo para a fidelização dos clientes. Exemplo: CRM usado por empresas como Coca-Cola
  - <b>SISTEMA</b>: Conjunto de elementos que interagem entre si em prol de solucionar e fazer funcionar um esquema.
  - <b>SECaaS</b>: é a terceirização da sua segurança digital para um provedor em nuvem, você assina um serviço que cuida de tudo isso via internet. Exemplo:Cloudflare
